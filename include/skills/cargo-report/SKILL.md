# Cargo report

Write every cargo report in this format:

1. A first line `STATUS: <ON TIME | DELAYED | AT RISK>`.
2. One sentence with the route, written as `<origin> -> <destination>`.
3. A bullet list of issues, each starting with the date in `YYYY-MM-DD` form.
4. End with `Report by: Cosmic Freight operations`.

Never include crew names.
